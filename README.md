# CrocoFile - Micro SaaS Tool #3 🐊

![CrocoFile](https://img.shields.io/badge/Status-Active-brightgreen) ![Local Processing](https://img.shields.io/badge/Privacy-Local_Processing-blue)

**CrocoFile** is my 3rd Micro SaaS tool! It is a fast, completely free, and incredibly secure browser-based file conversion and manipulation suite. 

Unlike most online file converters, **CrocoFile processes everything locally on your device.** This means zero uploads, total privacy, and incredibly fast processing speeds.

## 🚀 Features

CrocoFile provides a comprehensive suite of file management tools built directly for the web:

### 📄 PDF Tools
* **PDF Merge:** Combine multiple PDFs into a single document.
* **PDF Split:** Extract pages from a PDF.
* **PDF Rotate:** Quickly rotate PDF pages.
* **PDF Compress:** Reduce the file size of your PDFs.
* **PDF Organize:** Reorder, add, or delete pages in a PDF.
* **PDF Extract:** Extract text or specific data from PDFs.

### 🖼️ Image Tools
* **Image to PDF:** Convert JPG, PNG, and WebP images into a PDF document.
* **PDF to Image:** Extract pages from a PDF as high-quality images.
* **Image Compress:** Reduce the file size of images without losing quality.

### 📊 Document Conversion
* **Word to PDF:** Convert `.doc` and `.docx` files to PDF.
* **Excel / Spreadsheet to PDF:** Convert `.xls`, `.xlsx`, and `.csv` files to PDF.
* **HTML to PDF:** Convert HTML files and code into beautifully formatted PDFs.

## 🔒 Privacy by Design

We take privacy seriously. That's why CrocoFile is built with a **"No Uploads"** architecture. 
* **100% Client-Side:** All file parsing, compression, and conversion happens right in your browser.
* **No Servers:** Your files never leave your device.
* **No Limits:** Because processing is local, there are no artificial server limits or hidden paywalls.

## 🛠️ Tech Stack

* **Frontend:** Vanilla HTML, CSS, and JavaScript for maximum performance and a lightweight footprint.
* **Core Libraries:** `jspdf`, `fflate`, `fast-xml-parser`, `html-to-pdf-document`, `html2canvas`, and `reamkit`.
* **Bundler:** ESBuild for blazing-fast vendor module bundling.

## 🏃‍♂️ Running Locally

1. Clone the repository.
2. Install the build dependencies:
   ```bash
   npm install
   ```
3. Run a local development server (e.g., using `serve`):
   ```bash
   npx serve .
   ```
4. Open your browser and navigate to the provided localhost URL (usually `http://localhost:3000`).
