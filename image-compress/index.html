Compress Image to Exact KB

Compress images to an exact KB target. Runs in your browser.

Click or drop an image

JPG, PNG, or WebP

Use this image compressor when a website, form, exam application, or other portal sets a maximum file size in kilobytes. Choose a target size and process a JPG, PNG, or WebP image in your browser. The page offers a quick way to make an image smaller without sending its contents to a server. Compression changes image data, so the visual result may differ from the original; check the downloaded file before submitting it. This tool is designed for situations where a size limit matters more than keeping every original detail. Start with your image, set a target, and download the result when it is ready. No account is required.

It accepts JPG, PNG, and WebP images.
