Merge PDF

Combine multiple PDFs into one file. Drag to reorder.

Click or drop PDFs

Select 2 or more files

Combine several PDF documents into one file when you need to submit, store, or share related pages together. Add the PDFs you want to merge, arrange their order with drag and drop, and create a combined document in your browser. The original files are not uploaded for processing. This is useful for gathering separate forms, reports, or scanned documents into a single file before sending it onward. Check the page order and the resulting document after downloading, especially when the source files contain many pages. The merger handles PDF files and focuses on joining them; use the page tools if you also need to split, rotate, or remove individual pages.
